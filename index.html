Dev tools

One local HTML file. Address + sign run in the browser with ethers (CDN). Native TRX and USDT (TRC-20) are both supported; fees are paid by burning TRX, so there are no bandwidth or energy fields to fill. Native gRPC cannot run in a page, so Scan/Collect build the exact proto JSON for Postman or grpcurl.
